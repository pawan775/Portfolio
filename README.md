# Pawan Puthran – Portfolio Website

A modern, single-page portfolio website built with HTML, CSS, and JavaScript.

## 🚀 Features

- **Dark theme** with glassmorphism cards
- **Particle animation** background in the hero section
- **Typewriter effect** cycling through roles
- **Scroll-reveal animations** using Intersection Observer
- **Responsive design** with a hamburger mobile menu
- **Smooth scrolling** and active nav link highlighting
- **Contact form** with success feedback

## 📁 File Structure

```
Portfolio/
├── index.html          # Single-page portfolio
├── style.css           # All styles (dark theme, animations, responsive)
├── script.js           # Interactive features
├── README.md           # This file
└── assets/
    ├── photo-casual.jpg   ← Add your casual/friendly photo here (Hero section)
    ├── photo-formal.jpg   ← Add your formal/suit photo here (About section)
    └── cv.pdf             ← Add your CV/resume PDF here (Download button)
```

## 🖼️ Adding Your Photos

1. Place your **casual/friendly photo** at `assets/photo-casual.jpg`
   - Used in the **Hero section** (circular frame with glow effect)
   - Recommended: square crop, at least 600×600 px

2. Place your **formal/professional photo** at `assets/photo-formal.jpg`
   - Used in the **About section** (portrait frame)
   - Recommended: portrait crop (3:4 ratio), at least 600×800 px

3. Place your **CV/resume** at `assets/cv.pdf` to enable the Download CV button.

## ✏️ Customisation

- **Colors:** Edit CSS custom properties at the top of `style.css`
- **Projects:** Update the project cards in the `#projects` section of `index.html`
- **Skills:** Add/remove skills in the `#skills` section
- **Timeline:** Update your experience/education entries in `#experience`
